# StudyApp UI

应用共用的视觉系统与 GPUI 组件。桌面页面负责业务状态、命令、文件选择结果与持久化；此 crate 只接收状态并发出交互事件，不访问资料库、网络或用户文件。

- `design`：卡片 12px、控件 8px、列表行 6px、通知浮层 8px；标题栏及导航材质参数。
- `theme`：亮色、暗色和自定义主题解析；普通悬停、按下、选中和焦点状态；独立于强调色的错误、警告和成功颜色。
- `controls`：按钮和复选框，统一禁用、等待、指针、键盘激活和焦点行为。
- `components`：卡片、文档工具栏、列表行、指标、指针跟随信息浮层及滚动容器；`detail_list_row` 约束长标题与操作区域，确保虚拟列表行等宽。
- `settings_components`：分组表单、对齐设置行、32px 最小高度输入框、目录位置展示和可见行渲染。
- `settings_color`：按需创建的选色器；精确 HEX 输入在浮层内。
- `feedback`：居中对话框及焦点隔离。
- `notifications` / `notice_queue`：自适应浮动通知、重复通知、退出动画与独立刷新。
- `window_chrome`：自绘标题栏、窗口控制和平台拖动命中区域；关闭请求仍交给应用的保存保护。

桌面 crate 保留很薄的模块转导，现有页面与测试入口不需同时更名；实现与组件测试只保存在此 crate。不要在页面重新复制这些控件，也不要把业务 worker 放入 UI crate。`studyapp-core` 依赖仅用于读取已验证的外观配置类型。

导航使用系统合成材质与轻量透明着色；正文、编辑器、卡片与表单使用不透明背景。旧系统不支持 Mica 时保留普通着色导航，不使用 CPU 模糊。减少动画由系统偏好控制。

验证：`cargo test -p studyapp-ui --features ui-test` 使用 GPUI 测试平台，不打开真实桌面窗口。真实原生截图与输入验证仅在隔离 CI 运行。
