# 图片与云存储

## 本地图片

编辑器支持直接粘贴或拖入图片。应用按笔记分别管理图片，文件名包含添加时间和笔记名称。将外部跟踪笔记转为托管副本时，对应图片也会复制到托管位置，原文件保持不变。

编辑、保存和恢复草稿会保留已有托管图片的地址，不会反复创建图片副本。选择另存副本时，图片会随新笔记独立保存。

在「设置 → 存储 → 图片」选择本地保存，并通过文件夹选择按钮指定图片位置。更改位置影响后续添加的图片；已有图片仍按已记录的位置读取。备份时应同时保留这些目录。

## 云端或双保存

选择「云端」或「本地与云端」后，在同一页面选择目标：

- **复用笔记同步目标**：使用已配置的 WebDAV、文件夹或 NAS。
- **S3 兼容对象存储**：使用服务商提供的 S3 兼容接口，不限定某一家云服务。

填写并保存设置后，先测试连接，再尝试添加一张图片。已有图片可通过上传操作重试；切换保存方式不会自动上传全部历史图片。云端模式也会保留本地缓存。

## 配置 S3 兼容服务

| 字段 | 填写内容 |
| --- | --- |
| Endpoint | 服务商提供的 HTTPS S3 兼容入口，不含账户密码或对象路径 |
| Bucket | 已创建并授予读写权限的存储桶名称 |
| Region | 服务商指定的区域标识 |
| Access Key ID / Secret | 对该存储桶有读写权限的访问凭据 |
| 对象前缀 | 可选，用于将应用图片放在单独的路径下 |
| 寻址方式 | 按服务商要求选择虚拟主机或路径方式 |

服务需兼容 AWS Signature Version 4 和条件创建请求。请使用服务商的 S3 兼容入口，而不是控制台网址。不同服务商的兼容能力可能不同，以连接测试和实际图片上传结果为准。

此设置用于图片资源；Markdown 笔记的双向同步仍使用 [WebDAV 或文件夹 / NAS](sync-guide.md)。应用不负责创建存储桶或修改其权限。

## 换设备和常见问题

其他设备需要配置相同的图片目标及有效凭据，才能读取云端图片。密码由当前 Windows 用户保护，不随数据库备份迁移。

单张图片上限为 10 MiB。上传失败时，本地暂存内容会保留，可检查网络、地址与权限后重试。不要手动清空应用图片目录；单独导出的 Markdown 或数据库备份不包含完整图片资源。
