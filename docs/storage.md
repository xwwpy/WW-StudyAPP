# 资料库、备份与空间管理

## 选择资料库位置

在「设置 → 存储」打开资料库位置页面，通过文件夹选择按钮更改位置。请选择当前 Windows 用户可以读写的本地目录，推荐 NTFS 磁盘。设置会持久保存，下次启动继续使用所选位置。

如果启动时无法打开资料库，按照页面提示检查目录权限、移动磁盘连接或另一个应用实例。修复后点击「重试」，也可以重新选择资料库。重新选择位置不会自动搬走或删除原目录中的资料。

如果提示“程序运行在受限环境”，请将下载的发行包解压到普通用户目录后启动。程序所在位置的 Windows 安全标记可能限制其访问资料库；无需为此降低资料库权限或删除锁文件。

不要同时在两个应用实例中打开同一资料库，也不要直接用同步工具同步正在使用的数据库。笔记跨设备同步请使用应用的[同步功能](sync-guide.md)。

## 备份和恢复

在存储设置中导出备份，使用新的文件名保留不同日期的版本。恢复前应用会保留当前资料的备份，再恢复所选文件中的学习记录、笔记快照与历史。

数据库备份不包含图片、自定义图片目录、未保存草稿或同步账户。需要完整迁移时：

1. 将需要保留的草稿保存为笔记，导出资料库备份。
2. 单独备份图片资源和外部 Markdown 原文件。
3. 在新设备选择资料库位置，恢复备份，再重新关联外部文件。
4. 配置图片位置及同步账户，检查图片和笔记是否完整。

## 空间管理

「设置 → 存储 → 托管副本」可查看占用、搜索笔记、按名称或大小排序，并展开单项详情。

清理托管副本只处理应用管理的文件，不会删除外部跟踪的原文件。清理后仍可查看保留的历史内容；需要重新编辑时，根据提示恢复副本。已经清理或位置丢失的文件会显示对应状态。

删除、清理或恢复前请阅读确认框中的范围。文件路径默认隐藏，可在设置中开启显示。
