# 资料库、备份与空间管理

## 选择资料库位置

在「设置 → 存储」打开资料库位置页面，通过文件夹选择按钮更改位置。请选择当前 Windows 用户可以读写的本地目录，推荐 NTFS 磁盘。设置会持久保存，下次启动继续使用所选位置。

如果启动时无法打开资料库，按照页面提示检查目录权限、移动磁盘连接或另一个应用实例。修复后点击「重试」，也可以重新选择资料库。重新选择位置不会自动搬走或删除原目录中的资料。

旧版资料库可直接选择原目录继续使用。0.3.1 及以后兼容旧库缺少新增小组件默认配置的情况，无需手动创建配置文件或重建资料库；已有笔记、学习记录和设置会保留。

如果提示“程序运行在受限环境”，请将下载的发行包解压到普通用户目录后启动。程序所在位置的 Windows 安全标记可能限制其访问资料库；无需为此降低资料库权限或删除锁文件。

不要同时在两个应用实例中打开同一资料库，也不要直接用同步工具同步正在使用的数据库。笔记跨设备同步请使用应用的[同步功能](sync-guide.md)。

## 资料库正在使用中

同一资料库一次只能由一个应用实例使用。如果启动页提示正在使用，先确认另一个窗口是否仍然打开；不要删除锁文件。

当应用能够核实占用实例属于同一账户、程序身份一致且关联当前资料库时，可点击「关闭占用应用并重试」，阅读确认卡后选择「请求正常关闭并重试」。这不会强制结束进程或抢占窗口焦点。有未保存设置时，请回到占用窗口选择保存、放弃修改或继续编辑；继续编辑会取消这次关闭。草稿尚未持久保存或写入失败时，也不会跳过保存直接关闭。

只有实际使用锁释放后，等待窗口才会重新尝试打开资料库。点击「停止等待」只停止本窗口的等待，不撤回已经发出的关闭请求。如果对方取消、忙碌或等待超时，按照通知处理后可再次重试。

旧版本、其它账户、程序身份不符或无法安全核实的占用者需要手动关闭，再点击「重试」。应用不会关闭未知进程、删除锁文件或自动打开一份新的空资料库来绕过占用。

## 备份和恢复

在存储设置中导出备份，使用新的文件名保留不同日期的版本。恢复前应用会保留当前资料的备份，再恢复所选文件中的学习记录、笔记快照与历史。

数据库备份不包含图片、自定义图片目录、未保存草稿或同步账户。需要完整迁移时：

1. 将需要保留的草稿保存为笔记，导出资料库备份。
2. 单独备份图片资源和外部 Markdown 原文件。
3. 在新设备选择资料库位置，恢复备份，再重新关联外部文件。
4. 配置图片位置及同步账户，检查图片和笔记是否完整。

## 空间管理

「设置 → 存储 → 托管副本」可查看占用、搜索笔记、按名称或大小排序，并展开单项详情。

清理托管副本只处理应用管理的文件，不会删除外部跟踪的原文件。清理后仍可查看保留的历史内容；需要重新编辑时，根据提示恢复副本。已经清理或位置丢失的文件会显示对应状态。

删除、清理或恢复前请阅读确认框中的范围。文件路径默认隐藏，可在设置中开启显示。

## 检查文件完整性

在「设置 → 存储 → 空间概览」的「应用诊断」中点击「检查文件完整性」。应用从本仓库获取当前安装版本的已签名发行基线，只读比较程序、运行库及随附文档等已列出的文件；结果通过通知提示，点击「查看检查结果」可打开明细卡片，查看缺失、内容不符或无法安全读取的文件。

此操作不下载安装包、不替换或删除文件、不补安装记录，也不读取笔记正文或修改资料库。卸载程序、运行时生成的安装记录、便携启动脚本及未知邻接文件不属于发行文件校验范围。网络不可用、该版本未提供基线或签名无法验证时，会明确提示无法完成检查，不会显示文件完整。

如程序文件异常，请先备份资料并退出应用，再从发布页面下载完整安装包，按照[安装说明](updates.md)手动安装。
