# WW-StudyApp 0.1.3

- 更新提示改为紧凑卡片，更新日志支持 Markdown 标题、列表、加粗、代码和链接。
- 应用启动时检查更新，打开期间每小时自动检查；选择“稍后再说”后，本次运行不重复提醒同一版本。
- 点击“立即更新”后下载并验证安装包，保存当前草稿，安装完成后重新打开应用。Windows、通过 deb 安装的 Linux，以及安装到本机的 macOS 应用均支持此流程；需要权限时会使用系统授权。
- 设置页也可查看更新日志、手动检查和重试失败的更新。

Linux/macOS 的 0.1.2 用户需先手动安装本版，之后可使用应用内更新。macOS 安装包尚未经过 Apple 公证，首次启动方式见 README。安装包和 SHA-256 校验文件均可在本页下载。
