# WW-StudyApp 0.2.4

- 修正 Markdown 渲染后的文字选区：引用、行内代码、代码块和表格中的高亮覆盖实际文字，保留跨行、反向选择与多光标编辑。
- 加强浅色、深色主题的选区可辨识度。自定义主题可设置「选区背景」和「编辑器选中文字」颜色，预览后保存；对比度不足会提示，但不会替换所选颜色。
- Markdown 笔记、学习摘要、复习卡片与更新日志支持选中文字后右键「复制」。编辑器也可用菜单键或 Shift+F10 打开菜单，Enter 复制，Esc 关闭。
- 外部跟踪文件在目录中使用原始文件名（含扩展名），名称排序与拖动预览保持一致，不受正文一级标题影响。
- 学习记录列表按 Markdown 显示完整摘要；复习、摘要预览和笔记历史中的摘要使用一致排版。
- 跨版本更新时按版本展示此次升级包含的历史更新说明，更新卡片与设置页均可查看；较长日志继续独立滚动。
- Windows 误以管理员身份启动时，可通过同一用户的普通权限进程更新，安装和重启后的应用不继续继承管理员权限，保留原资料库与草稿。

0.2.3 及更早版本若仍提示先正常重启，请先退出并正常打开应用（不要选择「以管理员身份运行」）再更新，或手动安装本版。Windows 便携版 0.2.2 及更早版本请先退出并完整解压新版，此后可使用应用内更新。
