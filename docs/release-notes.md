# WW-StudyApp 0.2.3

- Windows 更新下载完成后可继续安装并自动重启，保留原资料库与草稿。安装版保持原目录，完整解压的便携版原位更新，不改变另一份安装版的注册信息与快捷方式。
- 更新安装支持中文、空格和特殊字符目录；其它目录中运行的 WW-StudyApp 不再阻挡本次安装。安装准备或启动失败后可以重试。
- 修正迁移目标、托管副本、维护结果与文件访问提示中的 Windows 路径显示，不再显示普通本地磁盘或网络路径的 `\\?\` 前缀。
- 更新日志可独立选中复制，不会连带选中弹窗下面的页面；关闭弹窗后恢复页面的正常选择。
- 笔记目录根据编辑器大小自动放在左侧、上方或浮层，也可手动选择左侧、右侧、上方、浮层或自动；位置与显示状态会记住。
- 目录显示与隐藏提供图标；可用目录右上角隐藏按钮或 Esc 收起目录，窄窗下侧栏暂时变为浮层以保留正文空间。

Windows 便携版 0.2.2 及更早版本请先退出并完整解压新版，之后可使用应用内更新。
