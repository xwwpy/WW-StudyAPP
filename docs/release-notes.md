# WW-StudyApp 0.3.0

## 计时与桌面小组件

- 今日学习页面固定显示当前计时详情和常用操作，正文滚动时仍可使用。点击桌面图标打开或收起小组件，两处共用同一计时状态，关闭小组件不会重置计时。
- 桌面小组件只保留计时卡片，工具采用图标并提供操作提示；支持拖动、缩放和置顶。Windows、macOS 使用原生窗口层级，Linux/XWayland 需要窗口管理器支持 EWMH 置顶。
- 小组件配置按显示、背景、颜色、预设和窗口行为分组，可滚动查看并实时预览。专注间隔、回答期限、正计时和倒计时不再设置人为时长区间；分钟配置须为正整数，无法表示的过大输入会明确提示。

## Markdown 与外观

- 支持安全 HTML 和有限行内样式，可在 Markdown 设置中关闭；代码围栏内的 HTML 仍显示为代码。
- 预览中的表格可拖动列宽、自动适应、恢复默认，并分别调整每列左对齐、居中或右对齐。支持全局默认与单表设置，不改写 Markdown 正文。
- 多级无序列表按实际嵌套层级显示不同符号，可选择多套预设或逐级自定义；任务列表、编号列表和复制的正文保持原样。
- 调色盘支持透明度与 RGBA 颜色，继续兼容六位 HEX 颜色。
- 改进 Markdown 首次打开及切换资料库后的加载，保留当前正文、只读状态和样式设置。

## 提示、更新与诊断

- 新增独立通知设置，可分别控制更新、计时、复习等事件，选择前台提示样式，并设置免打扰与安静时段。后台使用不抢焦点的桌面浮动卡片；必要确认仍会保留。
- 新版本通过版本旁的未读红点提示，点击后打开更新卡片。仅展示当前版本之后、目标版本以内的更新内容，每个版本独立显示。
- 资料库被占用时，可请求关闭经过验证的本应用实例并重试。对方仍按正常流程确认未保存内容、保存草稿后退出；无法核实的应用不会被强制关闭。
- 改进更新退出时的资料库释放流程，安装重启后重新打开原资料库。
- 存储页面提供只读的文件完整性检查，以已签名发行清单为基线核对应用文件，不下载或修复程序，也不修改笔记。
- 新增默认启用的日志，可选择输出等级、保存目录或关闭日志；支持轮转与保留上限，日志占用纳入空间统计。

Windows 0.2.3 及更早版本若提示先正常重启，请退出并直接双击应用（不要选择“以管理员身份运行”）后更新，或手动安装本版。Windows 便携版 0.2.2 及更早版本请先退出并完整解压新版。
