# WW-StudyApp 0.3.5

## 文档阅读与导入

- 支持导入 PDF、DOCX 并在应用内按原版式只读阅读，提供页码、翻页、适合宽度与缩放。PDF 按需加载可见页面，支持输入打开密码；DOCX 显示分页、表格、内嵌图片与页眉页脚，使用本机字体。
- 原件随历史版本及备份保留，可「导出原文…」保存新副本；不覆盖源文件，不做 OCR。单文件上限 32 MiB，最多阅读 2,000 页；DOCX 字体和复杂排版可能与 Word 略有差异。旧版 DOC 不支持。
- 支持导入 TXT、CSV、JSON、YAML、TOML、INI、LOG、RST、HTML、XML 等常见文本，以及带 BOM 的 UTF-16 文本。

## Markdown、列表与表格

- 安全 HTML 支持图片和链接，自动加载经应用校验的网络图片。阅读时可直接打开网页或邮件链接，编辑时按住 Ctrl（macOS 为 ⌘）点击；支持当前笔记的标题锚点。
- 空列表项按 Enter 退回上一层，一级列表恢复正文；Backspace 退出列表后不再残留错位缩进。保留代码块中的连续空格和 Tab，恢复对齐文本的正确显示。
- 目录标题支持加粗、强调和行内代码样式。
- 创建表格时可设置行列数；所有列均支持插入、复制、删除与左右移动，可统一对齐全部列或设置单列宽度，结构操作支持撤销与重做。

## 外观、路径与空间管理

- 新增暖纸、松林、晴海、雾紫、深海与石墨主题预设。统一输入框、焦点与禁用状态，重新排列设置项标签与控件。
- 窄笔记库中标题保持单行，拖动笔记卡片时中心跟随鼠标。
- 目录选择项持续显示当前绝对地址，包括默认图片与日志目录；悬停可查看完整路径。
- 存储空间使用文件管理器式树状展示，默认显示目录总占用，可逐层展开查看内部文件与子目录，并直接打开目录或定位文件。

## 通知

- 保存成功可显示笔记名称、保存地址或具体设置范围；失败提示说明可理解的原因与下一步，不在通知卡片默认显示诊断编号。
- 计时完成、提醒、保存成功、普通消息、警告与错误使用相应提示音，遵守通知声音开关与实际展示策略。
