# WW-StudyApp 0.3.6

## 笔记快照

- 在「设置 → 学习 → 笔记快照」选择定时扫描并保存、定时扫描但手动保存，或完全手动扫描并保存，并设置扫描间隔。
- 笔记库顶部新增「扫描并保存快照」入口。相同内容不会重复记录，已有快照、学习记录及版本历史保持兼容。
- 编辑器主动保存、自动草稿、导入基线与冲突保护继续独立工作。

## 选中状态与设置

- 页面导航、设置分类、配置选项与笔记列表区分选中和未选中状态，可分别自定义背景、文字、边框、圆角及导航标记。
- 设置项按卡片和分隔线分组；快照、气泡尺寸及堆叠等选项可从菜单选择。

## 提示与气泡

- 支持 Toast/HUD、角落操作卡片、顶部横幅、Alert/Dialog、Popover、Action Sheet、Snackbar 和活动面板，按用途展示在相应位置。
- 各类型可独立调整不透明度、边框、背景、宽高、圆角；颜色随应用明暗主题，也支持自定义 RGB/RGBA。
- 同时出现时可选择新的在下、新的在上、阶梯排列或单张排队，超出展示数量的通知继续等待。
- 提示内容支持简略、详细预设和逐字段开关。悬停提示可分别显示学习时间、上次复习及下次复习；错误详情与关闭入口保持可用。

## 文件统计与 Markdown

- 统计失败的文件按目录归类，默认只显示文件名和数量，鼠标悬停时查看原因。
- 无缩进正文紧接无序列表时从正文边缘显示；一级无序列表按一次 Enter 只新建一行。
- Tab 默认仅调整当前行，可在多级无序列表设置中开启连同子项调整；支持撤销与重做。
