# WW-StudyApp 0.3.2

- 统一修复页面在宽窗口下仍居中限宽、两侧大片留白的问题。今日学习计时卡片、复习计划、学习统计以及各设置分类会利用导航栏之外的剩余宽度。
- Markdown 正文默认自适应剩余空间，调整窗口、导航、笔记侧栏或目录后同步伸缩。阅读宽度设为 0 即可自适应，也可手动选择 480–1600 px 的固定阅读列。
- 旧版默认的 720 px 阅读列升级后自动改为自适应；其他自定义宽度保持不变。需要固定 720 px 时，可重新选择并保存。
- 修复通知或确认对话框出现时 Markdown 预览整块消失的问题，覆盖笔记阅读、连续编辑和外观样例预览。弹窗期间背景变暗且不可操作，关闭后保留内容、选区、阅读位置和撤销记录。
- 保留旧版资料库兼容性，无需重建资料库或手动补齐小组件默认配置文件。
- 修复计时小组件数字和选中模式按钮残留实色底的问题，背景不透明度最低可设为 0；文字、图标和进度保持清晰。
- 完善计时小组件整体缩放：支持直接输入 50–200% 的整数百分比、加减调整和一键恢复 100%。数字、标题、按钮、间距和窗口尺寸一起跟随缩放，预览和桌面小组件同步更新，保存后保留。
