# WW-StudyApp 0.4.0

## 代码阅读与笔记位置

- 笔记代码块提供「复制」「折叠 / 展开」。折叠只隐藏渲染内容，不修改 Markdown、保存结果或撤销记录；折叠后仍可复制完整代码。学习摘要、复习摘要及版本摘要也支持代码复制与折叠。
- 每份 Markdown 笔记记住上次阅读的内容位置，PDF／DOCX 原文档记住页码、页内位置和缩放。切换笔记或重启后恢复，不同资料库、笔记与文档类型互不影响；适合宽度模式下调整窗口仍保持当前页内位置，页码随实际可见页面更新。不保存文档内容或 PDF 密码。
- 阅读页标题显示实际文件名。草稿保存状态移至固定底栏，保存提示不再挤动正文。
- 未定义的 `[i]` 等引用保持普通文字，有目标的 Markdown 引用链接正常显示。
- 鼠标释放到窗口外、失焦或取消手势后，不再因悬停继续扩展选区。长代码和标题的滚动布局保持稳定，减少预览空白与来回跳动。
- 学习与复习摘要沿用笔记的 Markdown 外观配置，包括文字、代码与语法颜色、字号、字体、行高、表格样式和阅读宽度。

## 学习记录分类与分页

- 在统计页选择每页 20、50 或 100 条，使用首页、上一页、下一页和末页浏览记录。
- 支持按日期、关联笔记或学习状态分类，也可选择不分组；日期与状态筛选可继续组合使用。分类与筛选后从第一页开始，多笔记关联记录不会重复列出。

## 各有用途的通知与浮层

- 在「设置 → 通知与浮层」分别选择每种组件的结构布局，调整背景、透明度、边框、圆角、尺寸与内容字段；未自定义的属性持续跟随上级。
- Toast 使用单行短提示胶囊；HUD 展示非阻塞任务进度，有真实总量时才显示百分比。Snackbar 将提示、快捷操作和关闭入口放在同一条内。
- Banner 默认在内容顶部占位；角落通知卡片保留完整正文与操作分区。Alert 用于风险确认，Dialog 提供长内容或表单的独立滚动区和固定操作栏。
- Action Sheet 集中提供实际可用的新建与导入操作。分享与导出面板展示当前正文或明确历史版本的只读预览，导出使用新文件，不覆盖已有文件；任务活动面板汇总真实任务状态，收起后任务继续。
- Popover 用于点击打开的可交互详情；Popup Menu 用于命令选择，支持方向键、Enter、Esc 和子菜单。笔记、目录及设置菜单可独立选择标准或紧凑布局，超高菜单在内部滚动。
- Tooltip 仅显示悬停说明，可选择跟随鼠标或固定在控件旁，不含操作按钮，不抢占焦点。
- 各用途区域独立排列与排队，必要确认保持优先。组件默认内容与业务场景覆盖分开设置，必要风险说明与处置入口始终保留。

## 更清晰的设置与继承

- 设置使用可展开的分类树，支持拖动调整宽度；鼠标在窗口外松开后，返回悬停不再改变已调整的宽度。窄窗口改用分类抽屉，再次打开时恢复上次子页与阅读位置。
- 标题和保存／放弃栏固定，中间卡片独立滚动。普通卡片随可用宽度并排或堆叠，复杂内容独占一行，预览嵌入相关卡片；导航及其他按钮保留各自的最小点击高度，大字号下自动增加可点击尺寸。
- 在设置页按 Ctrl+F 搜索名称与说明，点击结果直接定位字段。搜索未启用模式的专用字段时只临时展开只读控件，不切换同步目标或云端服务，不运行任务。
- 数字支持直接输入与减／加，颜色支持色块、色值和调色盘，开关、时间段、路径、快捷键和敏感凭据分别使用对应控件。
- 支持继承的项显示来源和当前有效值，主动点击「自定义」后才创建覆盖；「恢复继承」重新跟随上级，不固定其他属性。
- 自定义主题使用统一选择控件，切换保留有效编辑；新建与应用集中在主题组底部，删除需单独确认，可通过放弃修改撤销。
- 工作区可直接填写主导航和资料库／笔记列表的首选宽度，调整排序与阅读目录显示、位置；窄窗只适配显示，不改写首选宽度。隐藏面板仍保留其宽度，重新显示可继续使用。
- 复习阶段与倒计时预设按页编辑，整组重置紧邻标题。免打扰关闭时保留起止时间草稿，重新启用后继续调整，跨午夜自动标注次日。
- 角落卡片和 Popup Menu 可独立设置舒适／紧凑间距或恢复继承；固定结构不适用的尺寸项就地说明并禁用，切回适用布局后继续编辑。Tooltip 的说明定位支持名称和说明精确搜索。
- 所有设置页共享草稿，翻页与切换分类保留未保存内容。外观即时预览，保存全部设置后持久化；放弃恢复原外观。单项、当前页和全部恢复分别限定作用范围。

## 快照与正文独立保存

- 在「设置 → 笔记与编辑 → 快照策略」选择三种扫描／保存方式，分别设置扫描间隔和内容稳定等待时间。
- Ctrl+S 保存当前正文，不因每次保存增加历史；自动草稿与快照策略独立。自动模式在内容稳定后保存变化，切换资料库或退出时尝试保存可安全读取的变化。
- 笔记库提供一键扫描并保存，以及「查看变化并勾选保存…」。可查看差异并选择记录哪些文件；预览后文件再次变化时需重新扫描，不保存过时内容。
- 相同内容不重复保存，不覆盖外部原文件，已有版本与学习记录保持兼容。

## Markdown、选中样式与文件统计

- Tab 默认调整当前列表项及其自身多行正文；可单独开启连同子列表调整。文字选区与多项选择遵守同一开关，支持撤销与重做。
- 无缩进正文紧接列表时按普通正文显示，不为显示效果改写源文。多级无序列表按页编辑，可选择预设或逐级自定义、恢复继承。
- 页面导航、设置分类、配置选项、笔记列表和目录树可分别覆盖选中与未选中样式，未覆盖属性持续继承全局。
- 统计失败项按可展开的目录树显示，文件作为叶子项；默认不显示失败原因，悬停文件名查看说明。
