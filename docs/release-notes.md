# WW-StudyApp 0.2.5

- 改进 Markdown 预览点击进入编辑的光标定位，减少渲染标记、换行和布局变化时的点击异常；拖选文字仍用于选择与复制。
- Markdown 正文按编辑器剩余空间调整宽度和留白，多列表格不再撑宽整篇正文；自定义阅读宽度继续保留。
- 今日学习的计时卡片统一为专注、正计时、倒计时三种模式，可设置名称和 1–180 分钟倒计时预设。专注模式沿用到点确认学习记录，通用计时不会自动计入学习记录，可选择“记录这段”。
- 点击“在桌面显示”或按 Ctrl+Shift+T 打开、隐藏桌面计时小组件，与主界面共享同一计时状态。窗口支持拖动、缩放，位置和显示状态在当前设备保留；Windows 可设置置顶。
- 在“设置 → 外观 → 计时小组件”中预览紧凑、标准、展开布局，调整背景、透明度、圆角、数字大小、强调色及显示项目；保存后保留，也可放弃修改或恢复本页默认。
- 小组件开启时关闭主窗口会最小化，计时继续；需要退出时使用小组件的“退出应用”。重新开始或切换已有一分钟以上进度的计时前会提示确认，已有学习记录不受影响。

Windows 0.2.3 及更早版本若提示先正常重启，请退出并直接双击应用（不要选择“以管理员身份运行”）后更新，或手动安装本版。Windows 便携版 0.2.2 及更早版本请先退出并完整解压新版。
