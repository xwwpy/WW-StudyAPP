# WW-StudyAPP 0.1.0

- 使用 Markdown 编写和管理笔记，支持图片、搜索和草稿自动保存。
- 记录学习内容，设置学习提醒与间隔复习，查看学习统计。
- 管理资料库和图片，备份恢复数据，通过 WebDAV、本地文件夹或 NAS 同步笔记。
- 自定义主题和快捷键，在设置中检查应用更新。

## 安装与使用

下载安装程序 `WW-StudyApp-0.1.0-windows-x86_64-Setup.exe`，按提示选择安装目录。也可下载便携版 ZIP，解压后运行 `START-WW-STUDYAPP.cmd`。

已有安装时会沿用原安装目录；如需更换目录，请先卸载并保留学习数据，再重新安装。

详见[使用说明](https://github.com/xwwpy/WW-StudyAPP/blob/v0.1.0/docs/user-guide.md)。
