# WW-StudyApp 0.3.1

- 修复升级后无法打开或切回旧资料库的问题。旧版资料库缺少新增的小组件默认配置时，仍可直接使用，无需手动创建配置文件。
- 保留原资料库中的笔记、学习记录和已有设置，不重建或覆盖旧版默认配置；小组件设置仍可正常保存并在重启后保留。
- 已存在但损坏的配置文件仍会提示检查，不会被当作旧版缺失文件静默忽略。
- 修复 Markdown 内容区未按剩余空间伸缩的问题。调整窗口、侧栏或顶部区域后，正文编辑区跟随可用宽高变化，空间较小时不再被固定最小高度撑出边界，顶部目录也会缩小以保留正文空间；已有阅读宽度设置保持不变。

如升级后曾切换到其他资料库，请在「设置 → 存储」重新选择原资料库目录。不要删除锁文件、数据库或其附属文件。
