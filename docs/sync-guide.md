# 笔记同步

## 同步范围

WebDAV 或本地文件夹 / NAS 同步保存笔记的最新 Markdown。学习时长、复习进度和完整版本历史保留在本地，换设备时请另行[备份和恢复资料库](storage.md)。

同步不会传播删除。删除同步目标上的文件不会删除本地笔记；本地仍存在的内容可能在下次同步时重新上传。

## 本地文件夹 / NAS

1. 在「设置 → 同步」选择「文件夹 / NAS」。
2. 选择已有、可读写的目录。NAS 需先在 Windows 中连接共享路径或挂载目录。
3. 保存设置，点击「测试连接」，再点击「立即同步」。首次使用建议先用一份测试笔记验证双向同步。
4. 如需定时同步，开启自动同步并设置间隔；仅在应用运行期间执行。

应用会在目标下使用自己的 StudyApp 子目录。不要同时通过其他工具编辑这个专用目录。文件系统需支持文件锁、硬链接与文件替换；部分 NAS 即使连接测试成功，也可能不支持写入，请以实际同步结果为准。

## WebDAV

1. 准备已有的 HTTPS WebDAV 目录，确认账户具有读取、创建和写入权限。
2. 在「设置 → 同步」选择「WebDAV」，填写最终目录地址、用户名和密码或应用密码。例如：`https://dav.example.com/my-folder/`。
3. 保存设置后测试连接，再进行同步。地址中不要包含用户名、密码或查询参数。
4. 自动同步间隔可设为 5–1440 分钟。

同一目标和用户名下，密码留空可保留已保存的密码；更改目标或用户名需要重新输入。密码由当前 Windows 用户保护，更换设备后需要重新配置。

服务必须支持带版本条件的写入（强 ETag）。如果服务不支持，应用会保留本地内容并提示失败，不会强行覆盖远端。

## 冲突与失败

双方都修改同一笔记时，应用会保留本地冲突副本，并接收远端版本。比较两份内容后，选择需要保留的部分继续编辑。外部跟踪文件不会被同步覆盖；接收到的修改会形成托管副本。

失败时先检查网络、账户权限与目标目录，再重试。切换或关闭同步不会删除已有笔记。仅连接相同的同步目标可以取回最新笔记，但不会恢复历史学习记录。

图片同步在「设置 → 存储 → 图片」中单独配置，详见[图片与云存储](object-storage.md)。
