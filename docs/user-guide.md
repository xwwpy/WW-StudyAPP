# 使用 WW-StudyApp

WW-StudyApp 将 Markdown 笔记、学习记录和间隔复习放在同一个本地资料库中。

## 开始使用

Windows 用户可选择安装版（解压 `installer-x64.zip` 后双击 `INSTALL-WW-STUDYAPP.cmd`），或完整解压便携包后双击 `START-WW-STUDYAPP.cmd`。安装、更新和卸载方式见[安装与更新说明](updates.md)。

1. 打开应用，在「笔记库」点击「＋」，新建笔记，或导入 Markdown 文件、文件夹。也可以直接将文件拖入窗口。
2. 点击正文开始编辑。未保存的内容自动保存在「草稿」中；点击保存后成为正式笔记，可以继续编辑。
3. 在「今日学习」记录本次学习内容，并关联笔记。应用运行期间会按设定间隔询问学习情况，超时未回答的时段会标记为未学习。
4. 到「复习计划」查看到期内容，复习后勾选完成；「学习统计」可查看学习时长与历史记录。

## 笔记与目录

- 点击「＋」创建目录。目录和笔记可拖入目标目录，也可通过右键菜单移动；「未分类」表示没有所属目录。
- 目录和由应用创建并保存的笔记可通过右键菜单重命名。笔记重命名只改变列表中的显示名称，不改变 Markdown 正文、原文件路径或历史记录；Enter 确认，Esc 取消。
- 笔记的右键菜单还提供移动、取消管理、删除草稿和在文件资源管理器中显示等适用操作。
- 使用搜索查找笔记，在排序菜单选择名称或更新时间。
- **A** 表示新增内容尚未记录学习，**M** 表示修改尚未记录学习；无标记表示与最近确认的学习内容一致。
- 「外部」笔记跟踪原文件；托管笔记由应用保存副本。取消管理不会删除外部原文件。
- 悬停气泡随鼠标移动，可查看学习时间、上次与下次复习时间；靠近窗口边缘时会自动调整位置。历史视图的内容随分栏宽度换行，调整分栏时保留阅读位置。

## Markdown 编辑

点击正文直接编辑，支持标题、表格、多级列表、任务列表、代码高亮和图片。

- 选中或进入代码块后，可输入语言名称并从候选中选择；不支持的名称会清空。
- 列表中按 Tab 缩进，Shift+Tab 减少缩进。默认 Ctrl+1…6 设置标题，Ctrl+0 恢复正文。
- 可以直接粘贴图片或拖入图片文件。托管图片按笔记分别整理，详见[图片与云存储](object-storage.md)。
- 保存保留当前编辑位置和已有图片地址。多份未完成笔记可在草稿箱中分别继续编辑或删除。

## 学习与复习

在「设置 → 学习」调整提醒间隔、回答时限和复习间隔。学习记录可以关联笔记与版本，也可以手动补录。复习完成后可撤销，避免误操作影响进度。

学习摘要支持 Markdown。填写提醒、手动补记或更正记录时，可直接输入 Markdown，也可选中文字后使用「标题、粗体、斜体、列表、引用、代码、表格」按钮快速排版。点击「预览」查看效果，再切回「编辑」继续修改；编辑和预览状态都可以保存。格式操作支持撤销与重做。

记录列表显示摘要文字，复习卡片显示 Markdown 排版。已有纯文本摘要也可继续编辑。摘要预览中的图片显示为图片说明，链接显示为文字。

「学习统计」提供学习时长、记录和复习情况，支持日期范围与记录筛选。

## 外观与快捷键

「设置 → 外观」可选择跟随系统、亮色、暗色或自定义主题，调整字体、间距和 Markdown 样式。点击色块选择颜色；对比度偏低时会给出可读性警告，仍允许使用所选颜色。

主题编辑中的 Markdown 预览会随可用空间调整大小：宽时与参数并排，窄时上下排列。打开颜色选择器或悬停候选颜色时保留当前预览，选定颜色后更新样式；调整窗口大小不会重置样例的阅读位置。

设置页顶部可搜索“字号”“同步”“备份”等功能，点击结果进入对应分类。新主题默认阅读宽度为 720 px，已保存的自定义宽度不会被覆盖。

「设置 → 快捷键」点击对应组合后直接按键录制。冲突项会标红，需要解决后保存。Esc 取消录制。

设置修改先保留为草稿，点击「保存全部设置」或按 Ctrl+S 才生效并持久化。如果修改过保存快捷键，则使用对应组合。离开时可选择保存、放弃或继续编辑。

各个可编辑设置页的「恢复本页默认」只重置当前页，其他分类的修改会保留；仍需保存后才生效。没有变化时重复保存不会增加配置副本。

侧栏可拖动调整宽度，拖至左缘隐藏；标题栏的侧栏图标可重新展开。拖动分隔条时显示候选位置，松手后调整。
