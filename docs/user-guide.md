# 使用 WW-StudyApp

WW-StudyApp 将 Markdown 笔记、学习记录和间隔复习放在同一个本地资料库中。

## 开始使用

Windows 用户可选择安装版（解压 `installer-x64.zip` 后双击 `INSTALL-WW-STUDYAPP.cmd`），或完整解压便携包后双击 `START-WW-STUDYAPP.cmd`。安装、更新和卸载方式见[安装与更新说明](updates.md)。

1. 打开应用，在「笔记库」点击「＋」，新建笔记，或导入 PDF、DOCX、Markdown、TXT、CSV、JSON、YAML、TOML、INI、日志等文本文件、文件夹。也可以直接将文件拖入窗口。
2. Markdown 和文本笔记可点击正文开始编辑；PDF/DOCX 在只读原文档阅读页查看。未保存的内容自动保存在「草稿」中；点击保存后成为正式笔记，可以继续编辑。
3. 在「今日学习」记录本次学习内容，并关联笔记。应用运行期间会按设定间隔询问学习情况，超时未回答的时段会标记为未学习。
4. 到「复习计划」查看到期内容，复习后勾选完成；「学习统计」可查看学习时长与历史记录。

## 笔记与目录

- 点击「＋」创建目录。目录和笔记可拖入目标目录，也可通过右键菜单移动；「未分类」表示没有所属目录。
- 目录和由应用创建并保存的笔记可通过右键菜单重命名。笔记重命名只改变列表中的显示名称，不改变 Markdown 正文、原文件路径或历史记录；Enter 确认，Esc 取消。
- 笔记的右键菜单还提供移动、取消管理、删除草稿和在文件资源管理器中显示等适用操作。
- 使用搜索查找笔记，在排序菜单选择名称或更新时间。
- **A** 表示新增内容尚未记录学习，**M** 表示修改尚未记录学习；无标记表示与最近确认的学习内容一致。
- 「外部」笔记跟踪原文件，目录显示原文件名（包含扩展名），不随正文标题改变；托管笔记由应用保存副本。取消管理不会删除外部原文件。
- 悬停气泡随鼠标移动，可查看学习时间、上次与下次复习时间；靠近窗口边缘时会自动调整位置。历史视图的内容随分栏宽度换行，调整分栏时保留阅读位置。

## 笔记快照

在「设置 → 笔记与编辑 → 快照策略」选择保存方式、扫描间隔和内容稳定等待时间，点击「保存全部设置」后生效：

- **定时扫描并保存**：按间隔检查文件，为停止变化并达到稳定等待时间的内容保存快照；默认扫描间隔为 60 秒、稳定等待为 3 秒，继续修改会重新等待。
- **定时扫描，手动保存**：后台检查文件状态和变化，不自动新增快照；准备记录版本时主动保存。
- **手动扫描并保存**：不在启动或后台扫描。点击笔记库顶部的刷新图标「扫描并保存快照」，或使用快照策略设置里的同名按钮，一次检查并保存当前变化。

相同内容不会重复保存。Ctrl+S 只保存当前正文，不因每次保存增加历史；重新打开笔记仍显示已保存的最新正文。自动草稿和正文保存独立于快照模式。自动模式在退出或切换资料库前会尝试保存可安全读取的变化；手动模式不会因此增加快照。无法安全完成时会明确提示，不覆盖外部文件。

点击「查看变化并勾选保存…」可查看待保存清单、与上次快照的差异，并只保存勾选项。预览后内容再次变化时会拒绝这批保存，重新扫描后再选择。刷新图标的悬停提示显示已检测到的待保存数量；完全手动模式需要主动扫描才知道外部变化。已有快照、版本标识与学习记录保持不变，无需重新导入。

## PDF、Word 与文本导入

在笔记库「＋」菜单选择「导入文档或笔记」，或将文件、目录拖入窗口。支持 PDF、DOCX，以及 Markdown、TXT、CSV、JSON、YAML、TOML、INI、LOG、RST、HTML、HTM、XML 等文本；旧版 `.doc` 不支持，请先在 Word 中另存为 `.docx`。文本可使用 UTF-8，带 BOM 的 UTF-16 文本也可导入。

- **原版式阅读**：PDF 按原页面显示；DOCX 保留字体样式、段落、表格、内嵌图片、页眉页脚及分页。DOCX 使用本机字体，字体缺失或复杂排版可能使分页与 Word 略有差异；PDF 中未嵌入的字体也可能被替代。
- **翻页和缩放**：使用上方页码、上一页、下一页及缩放菜单。默认适合宽度；PDF 按可见页面加载，滚动可继续阅读。加密 PDF 可输入打开密码，密码仅用于当前阅读，不写入资料库或诊断日志。
- **原件保护**：PDF/DOCX 只读，不转换成可编辑 Markdown，不进行 OCR，不覆盖原文件。原件内容随笔记版本和备份保留；在版本历史中可查看先前原件，通过「导出原文…」保存 PDF/DOCX 副本。导出时选择新文件名，已有文件不会被覆盖。
- **格式限制**：单份 PDF/DOCX 不超过 32 MiB，阅读最多 2,000 页。DOCX 解压总内容不超过 128 MiB，单个内部文件不超过 32 MiB。文件损坏、不支持的加密或过大的页面会显示说明，可导出原件使用其他阅读器查看。
- **链接与资源**：文档网页链接经应用打开；DOCX 不执行脚本、不加载外部网页或字体，外部内容片段不显示。Markdown/HTML 网络图片通过应用加载和校验。

## Markdown 编辑

点击正文直接编辑，支持标题、表格、多级列表、任务列表、代码高亮和图片。正文按实际剩余空间调整宽度与窄窗留白，较宽表格不会改变普通段落的阅读宽度。今日学习、复习、统计和设置页面也会利用导航栏之外的剩余宽度。正文编辑区随窗口、侧栏和顶部区域后的剩余宽高伸缩；顶部目录会在高度不足时缩小，为正文保留空间。

- 选中或进入代码块后，可输入语言名称并从候选中选择；不支持的名称会清空。
- 列表中按 Tab 缩进，Shift+Tab 减少缩进。默认只调整当前列表项的标记与自身多行正文，不移动未选中的子列表；在「设置 → 笔记与编辑 → 编辑行为」可开启同时调整子项。文字选区或明确选中多项时同样遵守此开关：关闭时只调整选中项及其自身正文，开启时连同子列表；明确选中的子项始终分别调整。一级无序列表按一次 Enter 只新建一行；无缩进正文紧接列表时也从正文边缘开始显示。默认 Ctrl+1…6 设置标题，Ctrl+0 恢复正文。空列表项按 Enter 会退回上一层，一级空项恢复普通正文；在正文开头按 Backspace 同样可退出一层列表，不残留列表缩进。
- 可以直接粘贴图片或拖入图片文件。托管图片按笔记分别整理，详见[图片与云存储](object-storage.md)。
- 代码块保留连续空格与 Tab 缩进，适合查看 INI、对齐文本和代码。
- 阅读时直接点击网页或邮件链接；编辑时按住 Ctrl（macOS 为 ⌘）点击。`#章节` 链接可跳到当前笔记的对应标题。
- 保存保留当前编辑位置和已有图片地址。多份未完成笔记可在草稿箱中分别继续编辑或删除。

选中文字后可右键选择「复制」；也可使用 Ctrl+C（macOS 为 ⌘C）。键盘可用菜单键或 Shift+F10 打开复制菜单，Enter 复制，Esc 关闭；没有选择文字时复制不可用。文字高亮覆盖引用、行内代码、代码块和表格中的实际选区，支持正反向和跨行选择。

### 代码块与阅读位置

代码块右上方提供「复制」和「折叠」；折叠后点击「展开」恢复显示，也可继续复制完整代码。折叠仅控制显示，不删除源文，不改变保存或撤销结果；切换源码视图仍能看到完整 Markdown。学习摘要、复习卡片和版本摘要中的代码块也使用这些操作。

Markdown 笔记按资料库和笔记分别记住上次阅读的内容锚点，切换笔记或重启后恢复；文档变化时会将位置限制在现有内容内。笔记阅读页标题显示实际文件名（含扩展名），草稿状态位于固定底栏。

### 表格创建、列操作与对齐

点击工具栏的「插入表格」，输入行数（包含表头）和列数，再点击「创建」。行数为 1–1,000、列数为 1–64，总单元格不超过 4,096。取消不会更改正文。

选择任意列后，在「更多列操作」中可在左侧或右侧插入列、复制、删除、左移或右移；表头和正文一起变化，空单元格与转义竖线保留。这些操作修改 Markdown 源文，支持撤销与重做；只读正文不能修改表格结构。删除唯一一列会删除整张表格，可立即撤销恢复。

在笔记正文的表头可使用表格显示工具：拖动列间手柄调整相邻两列宽度，或选择「按内容自适应列宽」「等宽列」。手柄获得焦点后可用左右方向键微调，Shift 加速，Esc 取消当前拖动。自适应按字体和内容分配宽度，长文字在单元格内换行；较大的表格采用有界内容采样。

先选择任意列，再使用左对齐、居中、右对齐或沿用源文对齐图标；选择「全部列」可统一调整对齐。「更多列操作」中的列宽百分比也支持最后一列。只读正文同样可调整显示方式。单张表格的显示覆盖保存在当前资料库，不改写 Markdown，不增加正文修订，也不影响文本撤销与复制；重开笔记、草稿转正式笔记与资料库备份恢复会保留配置。多个同表头表格按内容、章节与出现次序区分；完全相同的重复表格按出现次序匹配。

「设置 → 外观 → 主题与阅读 → Markdown 表格默认显示」可选择全局列宽与对齐，内置与自定义主题均适用。表格工具中的「恢复全局默认」会清除该表覆盖，重新跟随全局设置；全局设置需保存全部设置后保留。每张表可配置最多 64 列，每篇笔记保留最多 128 张表的显示覆盖。

### 多级无序列表

在「设置 → 外观 → 主题与阅读 → 多级无序列表」的「标记预设」菜单选择几何层级、经典、菱形、箭头或简约。每级先显示继承来源与当前标记，点击「自定义」后可选择圆、方块、三角、菱形、箭头、短横线、加号或星形等标记；「恢复继承」清除该级覆盖，重新跟随预设。层级每页显示四项，翻页保留全部草稿；也可通过设置搜索直接定位某一级。选择整套预设会替换逐级自定义，「恢复默认标记」恢复默认预设和各级继承，不改变列表缩进规则。可配置前八级，第九级起重复这八级。

层级按实际 Markdown 列表嵌套计算，有序列表也计入嵌套深度；只有无序列表的显示标记改变，有序编号和任务框保持原样。正文、草稿、主题样例及原生摘要使用相同配置，关闭 HTML 渲染仍可显示 Markdown 列表样式。编辑当前行时显示原始 `-`、`+` 或 `*`，不修改源文、文本撤销或复制结果。过长或嵌套过深的原生摘要会回退为普通 Markdown 排版。内置与自定义主题均适用；即时预览，保存全部设置后保留，放弃修改会恢复已保存设置。

### 安全 HTML

在「设置 → 外观 → 主题与阅读」使用「渲染 Markdown 中的安全 HTML 与行内样式」开关，默认开启。正文、未完成草稿、学习摘要与主题样例可显示安全的 HTML 排版；关闭后显示 HTML 原文。修改会即时预览，点击「保存全部设置」后保留；放弃修改会恢复原设置。围栏代码和行内代码中的 HTML 始终显示为代码。

正文支持加粗、斜体、下划线、删除线、高亮、段落、标题、引用、列表和表格等安全标签，以及颜色、背景色、有限字号、字重、行高、文本对齐、间距与边框等有限静态样式。例如：`<span style="color:#586D83;font-size:20px">重点</span>`。学习摘要也支持行内颜色与透明背景、字号与字重、行高、下划线与删除线，以及有限的段落对齐、间距和边框；混合样式文字可连续选取并右键复制为纯文本。原生摘要采用离线排版，具体布局与正文预览可能略有差异。

HTML 不能执行脚本、打开表单、加载嵌入页面或使用定位样式覆盖应用控件。笔记正文支持 `<img src="图片地址" alt="说明">` 与 `<a href="https://example.com">链接</a>`。图片通过应用的图片加载与校验流程显示，自动加载 HTTP(S) 网络图片；WebView 不直接请求原始资源。链接支持 HTTP(S)、邮件与当前笔记的章节跳转，不允许脚本、本地文件或系统命令地址。原生学习摘要仍以离线文字排版为主。过大或嵌套过深的 HTML 显示为原文。渲染与关闭开关都不会修改笔记源文。

操作按钮以图标为主，悬停可查看名称；键盘操作、屏幕阅读器名称、禁用与选中状态保持可辨。菜单、参数值及涉及删除、覆盖、放弃修改等必要确认仍保留明确文字。

## 计时与桌面小组件

“今日学习”顶部固定显示计时卡片；首次打开空资料库时也可使用，滚动下方学习记录或引导内容不会把它滚走。卡片显示计时名称、模式、进行／暂停／结束状态，以及已用时间；专注与倒计时还显示剩余时间、目标时长和进度，专注模式显示当前学习段。暂停／继续、记录和设置使用图标，悬停可查看操作名称。

点击设置图标可切换模式、修改名称和时长；倒计时支持在卡片的设置弹窗中选择预设分钟数，确认后才会开始新计时。提供三种模式：

- **专注**：沿用“设置 → 学习与复习”的提醒间隔，到点生成待确认的学习记录。提醒间隔和回答期限可填写正整数分钟，不设人为的时长区间；零值或无法安全表示的过大数值会提示，不会改写当前计时。
- **正计时**：从零开始累计，不自动生成学习记录；可暂停、继续或结束，不再到 24 小时自动停止。
- **倒计时**：选择预设或在“设置计时”中输入正整数分钟，不设人为的时长上限，到点停止并提示。可填写计时名称，结束后选择重新开始。

倒计时预设也支持超过 180 分钟；输入过大、无法安全表示的数值会提示，不会截断或改成其他时长。通用计时不会自动计入学习统计；点击“记录这段”可预填时长与计时名称，确认学习摘要后保存。切换模式、预设或重新开始时，如果当前进度已达到一分钟，会先提示确认；取消会保留当前进度，已有学习记录不会删除。

点击固定卡片右上角的桌面图标，或按 **Ctrl+Shift+T** 打开、隐藏桌面小组件。图标选中表示小组件已打开，悬停显示“显示桌面小组件”或“隐藏桌面小组件”；关闭小组件不会移除页面上的计时卡片，也不会重置当前计时。两处显示和控制同一计时，不会重复累计。窗口只保留计时卡片，打开时按实际内容收紧高度；布局或内容高度变化时重新适配，手动缩短后可在卡片内滚动。工具收在卡片内：拖动六点手柄图标移动窗口，拖动边缘改变大小；使用房屋图标返回主界面、设置图标打开外观、关闭图标仅关闭小组件。Windows、macOS 和支持 EWMH 的 Linux/XWayland 窗口管理器可用图钉切换置顶。图标选中表示已确认置顶；等待系统确认时暂不可重复操作。失败会以统一通知提示，可点击图钉重试，不会把未生效的请求显示为成功。位置和开合状态仅保存在当前设备，应用重新打开时恢复。

“设置 → 外观 → 计时小组件”按布局与显示、尺寸与背景、颜色与透明度、计时预设、窗口行为分组，可滚动到全部设置和实时预览。在这里选择紧凑、标准或展开布局，调整背景不透明度（0–100%）、圆角、整体缩放（50–200%）、强调色、秒数、进度和按钮等；展开布局还显示模式和倒计时预设。置顶使用当前平台的原生窗口层级；Linux 需要窗口管理器支持 EWMH 置顶协议，不支持时可继续使用普通窗口。外观修改同时更新预览和已打开的小组件，保存全部设置后保留；放弃修改会恢复之前的外观。“恢复本页默认”只影响小组件设置。背景不透明度为 0 时不再为数字或选中按钮保留实色底，文字、图标和进度保持清晰；选择“不透明”背景时固定使用实色。整体缩放可直接输入整数百分比，也可点击加减或 100% 复位，标题、数字、按钮、间距和窗口尺寸一起变化；拖动窗口边缘仍可单独调整大小。

**小组件开启时，关闭主窗口只会最小化，计时继续。需要真正退出，请点击卡片内的退出图标（悬停显示“退出应用”）。** 退出或安装更新仍会保存当前草稿。

## 学习与复习

在「设置 → 学习与复习」调整提醒间隔、回答时限和复习间隔。学习记录可以关联笔记与版本，也可以手动补录。复习完成后可撤销，避免误操作影响进度。

学习摘要支持 Markdown。填写提醒、手动补记或更正记录时，可直接输入 Markdown，也可选中文字后使用「标题、粗体、斜体、列表、引用、代码、表格」按钮快速排版。编辑时默认同时显示预览，正文输入和格式操作会更新预览；点击「隐藏预览」可专注输入，点击「显示预览」重新打开。空间不足时编辑区和预览区上下排列，两种状态都可以保存。摘要输入区与预览区可独立滚动，滚到边界不会带动学习记录页面；移到编辑区外可继续滚动页面。格式操作支持撤销与重做。

学习记录列表、复习卡片与摘要预览均显示 Markdown 排版，不再把摘要截成单行。选中文字后可右键选择「复制」。已有纯文本摘要也可继续编辑。摘要预览中的图片显示为图片说明，链接显示为文字。

「学习统计」提供学习时长、记录和复习情况，支持日期范围与记录筛选。

### 学习记录分类和翻页

在统计页的「全部学习记录」区域，可以按日期筛选，并选择全部、已学习、未学习或待回答。通过「分类显示」选择不分组、按日期、按笔记或按学习状态；关联多份笔记的同一记录只出现一次，没有关联笔记的记录单独归类。

底部选择每页 20、50 或 100 条，使用首页、上一页、下一页和末页翻页；页码与条目范围会一并显示。切换分类、日期、状态或每页条数后回到第一页，记录数量变化时页码自动限制到可用页面。

摘要预览、学习记录和复习摘要沿用当前笔记的 Markdown 语义外观，包括正文与代码字体、字号、行高、颜色、语法高亮、表格配置和阅读宽度。修改外观草稿时即时更新，保存或放弃全部设置时一并应用。

## 选中状态与设置布局

在「设置 → 外观 → 选中样式」设置全局选中和未选中项的背景、文字、边框、圆角与标记。页面导航与设置分类、配置选项、笔记／文件列表、目录树可分别覆盖；未自定义的属性持续跟随全局，单项「恢复继承」不会覆盖其他属性。正文文本选区、键盘焦点与悬停状态独立。

设置使用左侧分类树，分类可分别展开或收起。拖动分隔线可调整并记住分类树宽度；窄窗口改用标题旁的分类抽屉，选择页面后自动收起，变宽后恢复。再次打开设置会恢复上次子页和阅读位置，不额外保存未提交草稿。

右侧标题和保存／放弃栏固定，中间卡片独立滚动。宽窗口中适合并排的普通卡片使用双列，复杂内容占满一行；窄窗口回到单列。普通设置行宽时左右排列，窄时控件移到名称下方。短标签少量单选使用分段按钮，其余使用选择菜单；数字可直接输入或使用减／加按钮，单位和单项重置相邻。有序阶段逐行编辑并分页，翻页不会丢失未保存内容。

在「设置 → 外观 → 工作区」可直接输入主导航宽度（128–320 px）和资料库／笔记列表宽度（160–440 px），或使用加减与单项重置。隐藏面板时保留宽度但禁用调整，重新显示后原位恢复；窄窗仅临时压缩显示，不覆盖首选宽度。这里也可选择笔记排序，以及阅读目录的显示状态和自动、左侧、右侧、顶部或悬浮位置。全部先修改共享草稿，保存后保留，放弃修改可恢复；Ctrl+F 可定位到具体选项。

## 外观与快捷键

「设置 → 外观」可选择跟随系统、亮色、暗色或自定义主题，调整字体、间距和 Markdown 样式。在「主题编辑」的「内置主题」菜单可选择暖纸、松林、晴海、雾紫、深海或石墨，选用后可继续编辑；点击「保存全部设置」后保留。点击色块打开共享调色盘，可选常用颜色、当前运行期间最近应用的颜色，或调整色相、饱和度、明度与不透明度。棋盘格表示透明区域，原色与预览并排显示。

调色盘会遵循浮层高度设置；高度不足时颜色、滑块和 HEX 输入区域可独立滚动，底部“应用”和“取消”保持可见。精确输入支持 `#RRGGBB` 和 `#RRGGBBAA`：末两位 `00` 为完全透明、`FF` 为完全不透明，例如 `#586D8380` 约为半透明；已有六位颜色保持完全不透明。点击“应用”更新设置草稿，点击“取消”、关闭弹出层或切换分类会放弃尚未应用的颜色；点击“保存全部设置”后才会保留到下次启动。Markdown 颜色还可选择“自动适配”。对比度提示按透明颜色与实际背景叠加后的效果计算，不会阻止保存合法的低对比度颜色。原生窗口背景会与应用底色合成，不会把文字和按钮一起变淡；Markdown 颜色与计时小组件强调色保留透明度。

已保存到草稿中的主题统一在「自定义主题」选择控件中切换；切换会保留当前主题的有效编辑，色值等输入无效时会留在原主题并提示修正。新建和应用操作位于主题组底部；「删除所选主题草稿…」需单独确认，删除当前主题后切换为跟随系统，不影响其他设置。保存全部设置后保留删除结果，放弃修改可恢复。

自定义主题的 Markdown「文字与版式」颜色中可调整「选区背景」与「编辑器选中文字」；选区背景也用于摘要、更新日志等原生文字视图。浅色与深色主题默认使用更明显的选区颜色。选区与正文背景过于接近、或选中文字对比度不足时会提示，仍可预览和保存所选样式。

主题编辑中的 Markdown 预览嵌入主题卡片，默认展开，可手动收起；预览高度受限，内容内部滚动。打开颜色选择器或悬停候选颜色时保留当前预览，调整滑块或输入色值会临时更新样例，应用后更新草稿、取消后恢复；调整窗口大小不会重置样例的阅读位置。

在设置页按 Ctrl+F 唤出全局搜索，搜索名称与说明；结果浮层显示所属分类和匹配说明，点击后进入子页并定位设置项，Esc 或点击外部关闭，不改变当前配置。搜索尚未启用的图片云端或其他同步目标的专用字段时，会临时展开对应字段供查看；非当前模式的字段禁用并说明原因，不会替你切换保存方式、云端服务或同步目标。阅读宽度默认设为 0，表示自适应剩余空间；可改为 480–1600 px 的固定阅读列。旧版默认的 720 px 阅读列升级后改为自适应，其他自定义宽度保持不变；仍可手动重新选择 720 px 并保存。

「设置 → 快捷键」点击对应组合后直接按键录制。冲突项会标红，需要解决后保存。Esc 取消录制。

图片、日志与文件夹同步的可编辑路径始终独占一行，可直接输入或选择目录，并提供单项重置。选择路径只修改草稿，不迁移或删除文件；更换资料库位置仍需单独确认。

设置修改先保留为全部分类共享的草稿，切换分类不会丢失编辑；外观即时预览，功能性规则在保存后生效。点击「保存全部设置」或按 Ctrl+S 才持久化，放弃会同时恢复原外观。如果修改过保存快捷键，则使用对应组合。离开时可选择保存、放弃或继续编辑。

单项重置只改对应值，有继承关系的项可恢复继承；「恢复本页默认」只重置当前子页，「恢复全部默认」作用于全部设置，两种整页恢复会先确认影响范围；恢复都先修改草稿，仍可放弃，保存后才保留。没有变化时重复保存不会增加配置副本。

侧栏可拖动调整宽度，拖至左缘隐藏；标题栏的侧栏图标可重新展开。拖动分隔条时显示候选位置，松手后调整。

## 通知与提醒

在「设置 → 通知与浮层 → 通知规则与场景」分别控制更新、计时、复习、保存、同步、导入导出、位置迁移、完整性检查、图片和文件操作等提示。各场景直接展开，条目较多时分页；可单独设置前台、后台渠道与适用的前台组件。默认按真实用途分配，必要确认不能替换为自动消失的提示。主动保存成功默认关闭；自动保存成功不会反复弹出通知。

「设置 → 通知与浮层」为每种组件提供独立子页，可切换结构布局并调整外观；未自定义的尺寸和颜色持续继承全局／组件默认。

- **Toast** 是单行短提示胶囊，无标题和操作按钮；**HUD** 是非阻塞任务进度，仅在有真实总量时显示百分比，否则使用不定进度。
- **Snackbar** 将文字、真实快捷操作与关闭入口放在底部同一条内；**Banner** 默认在内容顶部占位，**角落通知卡片** 保留标题、完整正文与操作分区，可内部滚动。
- **Alert** 用于必须确认的风险说明；**Dialog** 用于长内容和表单，标题、内容滚动区、底部操作栏分离。
- **Action Sheet** 展示实际支持的新建／导入操作，取消单独放置；危险操作仍需二次确认。
- **分享与导出** 面板展示所选正文或明确历史版本的只读预览，支持选择新文件导出原格式，不覆盖已有文件；关闭不执行导出。
- **任务活动** 面板汇总同步、更新和迁移的真实状态，默认位于右侧；收起不取消任务，仅提供当前任务实际支持的操作。
- **Actionbar** 只显示选区实际支持的操作，可选择选区附近悬浮或内容顶部占位；**Popover** 是点击打开、可交互的控件详情；**Popup Menu** 是支持键盘导航与子菜单的命令菜单。笔记、目录和设置选择菜单使用独立的菜单外观，可选择标准或紧凑布局，调整背景、边框、圆角、宽度及最大高度；内容超过可用高度时在菜单内滚动。方向键跳过禁用项、说明和分隔线，Enter 执行命令或进入子菜单，Esc 关闭。
- **Tooltip** 仅显示悬停文字，可选择跟随鼠标或固定在控件旁，不含操作按钮，不抢占焦点。

「分区与堆叠」分别设置各用途区域的排列与可见数量。空间不足时排队，不遮住其他提示的操作入口；必要模态确认优先，主动打开的菜单、详情和任务面板不进入普通提示队列。

内容字段分为组件默认和场景覆盖两层，均仅列真实可用字段，支持简略／详细预设。未自定义的场景字段跟随组件默认，单项恢复继承不会冻结其他字段；必要风险说明与处置入口不能关闭。悬停元数据可分别选择来源、状态、学习、复习与下次复习信息，普通帮助和错误详情不因元数据开关隐藏。组件预览不运行实际任务、不导出文件，也不播放提示音。

一般消息按设定时间退出；错误和重要错误需手动关闭或点击相应操作。悬停可暂停普通消息的倒计时。重复的同类业务事件会合并计数，保存提示会说明保存的笔记名称与位置，或已保存的设置范围；失败提示给出权限、占用、磁盘空间、网络等可理解的原因，不默认展示冗长技术编号。关闭错误提示不会丢弃草稿、把失败改为成功，或跳过删除、覆盖及未保存内容等必要确认。

应用处于后台时使用独立桌面浮动卡片，不主动打开主窗口。窗口只保留提示卡片，随内容与叠放数量收紧或展开，不因显示、调整大小或关闭提示而切换当前窗口。默认隐藏具体内容，可在通知设置中调整；浮动窗口暂时不可用时，保留待展示事件并在返回应用后提示，不改用系统通知。也可开启免打扰、设定跨午夜的安静时段，并决定重要错误是否例外。提示音默认关闭，开启后只在通知实际呈现时尝试播放相应声音，区分成功、提醒、警告和错误；计时结束使用专门的完成提示。被关闭或免打扰抑制的通知不会发声，同一提示切换展示位置不会重复播放。声音使用系统现有提示音，受系统音量、静音与可用音频组件影响。

更新红点有独立开关。隐藏红点不会标记更新为已读，也不会移除手动检查、查看更新内容和安装更新的入口。分类开关与通知外观分别支持恢复本页默认，修改均需「保存全部设置」后保留。

## 本地日志

在「设置 → 日志」开启或关闭日志，选择输出等级与保存目录。默认开启 **Info**：Error 只输出错误，Warn 增加警告，Info 增加常规运行信息，Debug 与 Trace 提供更细的阶段和计数。日志开关与通知、免打扰、提示音相互独立。

目录留空时使用应用本地数据下的 `logs` 文件夹；也可点击「选择文件夹」或直接在常驻输入框填写绝对路径。选择目录、调整等级和恢复默认都只修改草稿，点击「保存全部设置」后生效。切换位置不会迁移或删除旧日志；「使用默认位置」清空自定义目录。

日志只保存在本机，不上传，任何等级都不记录笔记正文、剪贴板、密码、令牌、网址、完整文件路径或技术堆栈。日志中的事件编号用于关联对应业务结果，不在普通通知中默认展示；重复提示会记录来源编号与显示编号的关联，即使关闭相应通知，启用的日志仍按等级输出。

日志使用有界后台队列，过载时合并记录丢弃数量，不阻塞保存或编辑。最多保留 5 个日志文件，每个不超过 2 MiB，达到上限后轮转应用自己登记的文件；同名未知文件、链接和其他应用占用的位置不会被强行替换。目录不可用时会提示一次，笔记与其他功能仍可继续使用，可选择其他位置。退出和更新前会尝试刷新，迁移前会释放日志句柄。

「设置 → 存储与备份 → 空间概览」包含默认或当前自定义位置中已登记的日志文件；不会为统计日志而扫描自定义目录中的其他文件。与资料库或应用本地数据重叠的文件只计算一次；不能安全核对时显示统计不完整。

## 笔记目录与大文件

打开 Markdown 笔记后，点击工具栏的侧栏图标（悬停显示「显示目录」）显示标题目录，再次点击或使用目录右上角的隐藏图标关闭。目录默认根据编辑器实际空间选择左侧、上方或浮层；可从「目录位置」选择自动、左侧、右侧、上方或浮层。所选位置和显示状态会记住；窄窗下左右侧栏会暂时变为浮层，变宽后恢复，避免挤占正文。目录支持标题中的粗体、斜体与行内代码等简单样式，不显示这些样式的 Markdown 标记，也不会执行 HTML。目录按标题层级显示，点击标题左侧箭头可展开或收起子章节，也可使用「全部展开」「全部收起」。点击标题跳转到对应位置，当前章节会高亮；编辑标题或切换笔记后目录随之更新。目录获得焦点时，可用上下方向键选择、左右方向键展开收起、Enter 跳转，Esc 隐藏目录并返回开关。目录仅显示在笔记中，学习摘要不显示目录。

历史快照列表纵向滚动，快照时间与滚动条分开显示。笔记不设固定文件大小上限，导入、编辑、保存、草稿恢复和同步均可处理较大的 Markdown 文件；实际处理速度取决于设备与内容。图片预览不再设固定张数上限。

通知与 Markdown 预览：弹出通知或确认对话框时，正文保持可见，模态卡片外的背景变暗且不可编辑或滚动；关闭后保留原来的内容、选区和阅读位置。外观设置中的独立 Markdown 样例同样适用。
