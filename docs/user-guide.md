# 使用 WW-StudyApp

WW-StudyApp 将 Markdown 笔记、学习记录和间隔复习放在同一个本地资料库中。

## 开始使用

Windows 用户可选择安装版（解压 `installer-x64.zip` 后双击 `INSTALL-WW-STUDYAPP.cmd`），或完整解压便携包后双击 `START-WW-STUDYAPP.cmd`。安装、更新和卸载方式见[安装与更新说明](updates.md)。

1. 打开应用，在「笔记库」点击「＋」，新建笔记，或导入 Markdown 文件、文件夹。也可以直接将文件拖入窗口。
2. 点击正文开始编辑。未保存的内容自动保存在「草稿」中；点击保存后成为正式笔记，可以继续编辑。
3. 在「今日学习」记录本次学习内容，并关联笔记。应用运行期间会按设定间隔询问学习情况，超时未回答的时段会标记为未学习。
4. 到「复习计划」查看到期内容，复习后勾选完成；「学习统计」可查看学习时长与历史记录。

## 笔记与目录

- 点击「＋」创建目录。目录和笔记可拖入目标目录，也可通过右键菜单移动；「未分类」表示没有所属目录。
- 目录和由应用创建并保存的笔记可通过右键菜单重命名。笔记重命名只改变列表中的显示名称，不改变 Markdown 正文、原文件路径或历史记录；Enter 确认，Esc 取消。
- 笔记的右键菜单还提供移动、取消管理、删除草稿和在文件资源管理器中显示等适用操作。
- 使用搜索查找笔记，在排序菜单选择名称或更新时间。
- **A** 表示新增内容尚未记录学习，**M** 表示修改尚未记录学习；无标记表示与最近确认的学习内容一致。
- 「外部」笔记跟踪原文件，目录显示原文件名（包含扩展名），不随正文标题改变；托管笔记由应用保存副本。取消管理不会删除外部原文件。
- 悬停气泡随鼠标移动，可查看学习时间、上次与下次复习时间；靠近窗口边缘时会自动调整位置。历史视图的内容随分栏宽度换行，调整分栏时保留阅读位置。

## Markdown 编辑

点击正文直接编辑，支持标题、表格、多级列表、任务列表、代码高亮和图片。正文按实际剩余空间调整宽度与窄窗留白，较宽表格不会改变普通段落的阅读宽度。

- 选中或进入代码块后，可输入语言名称并从候选中选择；不支持的名称会清空。
- 列表中按 Tab 缩进，Shift+Tab 减少缩进。默认 Ctrl+1…6 设置标题，Ctrl+0 恢复正文。
- 可以直接粘贴图片或拖入图片文件。托管图片按笔记分别整理，详见[图片与云存储](object-storage.md)。
- 保存保留当前编辑位置和已有图片地址。多份未完成笔记可在草稿箱中分别继续编辑或删除。

选中文字后可右键选择「复制」；也可使用 Ctrl+C（macOS 为 ⌘C）。键盘可用菜单键或 Shift+F10 打开复制菜单，Enter 复制，Esc 关闭；没有选择文字时复制不可用。文字高亮覆盖引用、行内代码、代码块和表格中的实际选区，支持正反向和跨行选择。

### 安全 HTML

在「设置 → 外观 → 主题与阅读」使用「渲染 Markdown 中的安全 HTML 与行内样式」开关，默认开启。正文、未完成草稿、学习摘要与主题样例可显示安全的 HTML 排版；关闭后显示 HTML 原文。修改会即时预览，点击「保存全部设置」后保留；放弃修改会恢复原设置。围栏代码和行内代码中的 HTML 始终显示为代码。

正文支持加粗、斜体、下划线、删除线、高亮、段落、标题、引用、列表和表格等安全标签，以及颜色、背景色、有限字号、字重、行高、文本对齐、间距与边框等有限静态样式。例如：`<span style="color:#586D83;font-size:20px">重点</span>`。学习摘要也支持行内颜色与透明背景、字号与字重、行高、下划线与删除线，以及有限的段落对齐、间距和边框；混合样式文字可连续选取并右键复制为纯文本。原生摘要采用离线排版，具体布局与正文预览可能略有差异。

HTML 不能执行脚本、打开表单、加载嵌入页面或使用定位样式覆盖应用控件。HTML 中的图片不直接加载原始地址，链接不获得额外的打开权限；正常 Markdown 图片继续使用既有的图片配置。过大或嵌套过深的 HTML 显示为原文。渲染与关闭开关都不会修改笔记源文。

操作按钮以图标为主，悬停可查看名称；键盘操作、屏幕阅读器名称、禁用与选中状态保持可辨。菜单、参数值及涉及删除、覆盖、放弃修改等必要确认仍保留明确文字。

## 计时与桌面小组件

今日学习的计时卡片提供三种模式：

- **专注**：沿用“设置 → 学习”的提醒间隔，到点生成待确认的学习记录。
- **正计时**：从零开始累计，不自动生成学习记录；可暂停、继续或结束，不再到 24 小时自动停止。
- **倒计时**：选择预设或在“设置计时”中输入正整数分钟，不设人为的时长上限，到点停止并提示。可填写计时名称，结束后选择重新开始。

倒计时预设也支持超过 180 分钟；输入过大、无法安全表示的数值会提示，不会截断或改成其他时长。通用计时不会自动计入学习统计；点击“记录这段”可预填时长与计时名称，确认学习摘要后保存。切换模式、预设或重新开始时，如果当前进度已达到一分钟，会先提示确认；取消会保留当前进度，已有学习记录不会删除。

点击“在桌面显示”或按 **Ctrl+Shift+T** 打开、隐藏桌面小组件。两处显示和控制同一计时，不会重复累计。窗口只保留计时卡片，打开时按实际内容收紧高度；布局或内容高度变化时重新适配，手动缩短后可在卡片内滚动。工具收在卡片内：拖动六点手柄图标移动窗口，拖动边缘改变大小；使用房屋图标返回主界面、设置图标打开外观、关闭图标仅关闭小组件。Windows 可用图钉图标切换置顶状态。位置和开合状态仅保存在当前设备，应用重新打开时恢复。

“设置 → 外观 → 计时小组件”按布局与显示、尺寸与背景、颜色与透明度、计时预设、窗口行为分组，可滚动到全部设置和实时预览。在这里选择紧凑、标准或展开布局，调整背景透明度、圆角、数字大小、强调色、秒数、进度和按钮等；展开布局还显示模式和倒计时预设。Windows 支持窗口置顶。外观修改同时更新预览和已打开的小组件，保存全部设置后保留；放弃修改会恢复之前的外观。“恢复本页默认”只影响小组件设置。透明度只影响背景，文字和按钮保持清晰。

**小组件开启时，关闭主窗口只会最小化，计时继续。需要真正退出，请点击卡片内的退出图标（悬停显示“退出应用”）。** 退出或安装更新仍会保存当前草稿。

## 学习与复习

在「设置 → 学习」调整提醒间隔、回答时限和复习间隔。学习记录可以关联笔记与版本，也可以手动补录。复习完成后可撤销，避免误操作影响进度。

学习摘要支持 Markdown。填写提醒、手动补记或更正记录时，可直接输入 Markdown，也可选中文字后使用「标题、粗体、斜体、列表、引用、代码、表格」按钮快速排版。编辑时默认同时显示预览，正文输入和格式操作会更新预览；点击「隐藏预览」可专注输入，点击「显示预览」重新打开。空间不足时编辑区和预览区上下排列，两种状态都可以保存。摘要输入区与预览区可独立滚动，滚到边界不会带动学习记录页面；移到编辑区外可继续滚动页面。格式操作支持撤销与重做。

学习记录列表、复习卡片与摘要预览均显示 Markdown 排版，不再把摘要截成单行。选中文字后可右键选择「复制」。已有纯文本摘要也可继续编辑。摘要预览中的图片显示为图片说明，链接显示为文字。

「学习统计」提供学习时长、记录和复习情况，支持日期范围与记录筛选。

## 外观与快捷键

「设置 → 外观」可选择跟随系统、亮色、暗色或自定义主题，调整字体、间距和 Markdown 样式。点击色块打开共享调色盘，可选常用颜色、当前运行期间最近应用的颜色，或调整色相、饱和度、明度与不透明度。棋盘格表示透明区域，原色与预览并排显示。

精确输入支持 `#RRGGBB` 和 `#RRGGBBAA`：末两位 `00` 为完全透明、`FF` 为完全不透明，例如 `#586D8380` 约为半透明；已有六位颜色保持完全不透明。点击“应用”更新设置草稿，点击“取消”、关闭弹出层或切换分类会放弃尚未应用的颜色；点击“保存全部设置”后才会保留到下次启动。Markdown 颜色还可选择“自动适配”。对比度提示按透明颜色与实际背景叠加后的效果计算，不会阻止保存合法的低对比度颜色。原生窗口背景会与应用底色合成，不会把文字和按钮一起变淡；Markdown 颜色与计时小组件强调色保留透明度。

自定义主题的 Markdown「文字与版式」颜色中可调整「选区背景」与「编辑器选中文字」；选区背景也用于摘要、更新日志等原生文字视图。浅色与深色主题默认使用更明显的选区颜色。选区与正文背景过于接近、或选中文字对比度不足时会提示，仍可预览和保存所选样式。

主题编辑中的 Markdown 预览会随可用空间调整大小：宽时与参数并排，窄时上下排列。打开颜色选择器或悬停候选颜色时保留当前预览，调整滑块或输入色值会临时更新样例，应用后更新草稿、取消后恢复；调整窗口大小不会重置样例的阅读位置。

设置页顶部可搜索“字号”“同步”“备份”等功能，点击结果进入对应分类。新主题默认阅读宽度为 720 px，已保存的自定义宽度不会被覆盖。

「设置 → 快捷键」点击对应组合后直接按键录制。冲突项会标红，需要解决后保存。Esc 取消录制。

设置修改先保留为草稿，点击「保存全部设置」或按 Ctrl+S 才生效并持久化。如果修改过保存快捷键，则使用对应组合。离开时可选择保存、放弃或继续编辑。

各个可编辑设置页的「恢复本页默认」只重置当前页，其他分类的修改会保留；仍需保存后才生效。没有变化时重复保存不会增加配置副本。

侧栏可拖动调整宽度，拖至左缘隐藏；标题栏的侧栏图标可重新展开。拖动分隔条时显示候选位置，松手后调整。

## 通知与提醒

在「设置 → 通知」分别控制更新、计时、复习、保存、同步、导入导出、位置迁移、完整性检查、图片和文件操作等提示。展开某一类别，可单独设置前台、后台是否提示，以及该类别使用的前台样式。主动保存成功默认关闭；自动保存成功不会反复弹出通知。

在「设置 → 外观 → 通知」选择轻量气泡、角落操作卡片、顶部悬浮横幅、居中卡片或控件定位气泡，并调整位置、停留时间、叠放数量、宽度、圆角、间距、颜色、阴影和动画。控件定位气泡只依附当前可见的对应控件；控件不在当前页面或已滚出视口时，改为角落卡片。预览只展示外观，不触发实际提醒或声音。

一般消息按设定时间退出；错误和重要错误需手动关闭或点击相应操作。悬停可暂停普通消息的倒计时。重复的同类业务事件会合并计数，卡片上的事件编号用于关联诊断。关闭错误提示不会丢弃草稿、把失败改为成功，或跳过删除、覆盖及未保存内容等必要确认。

应用处于后台时使用独立桌面浮动卡片，不主动打开主窗口。默认隐藏具体内容，可在通知设置中调整；浮动窗口暂时不可用时，保留待展示事件并在返回应用后提示，不改用系统通知。也可开启免打扰、设定跨午夜的安静时段，并决定重要错误是否例外。提示音默认关闭，开启后只在通知实际呈现时尝试播放系统提示音。

更新红点有独立开关。隐藏红点不会标记更新为已读，也不会移除手动检查、查看更新内容和安装更新的入口。分类开关与通知外观分别支持恢复本页默认，修改均需「保存全部设置」后保留。

## 本地日志

在「设置 → 日志」开启或关闭日志，选择输出等级与保存目录。默认开启 **Info**：Error 只输出错误，Warn 增加警告，Info 增加常规运行信息，Debug 与 Trace 提供更细的阶段和计数。日志开关与通知、免打扰、提示音相互独立。

目录留空时使用应用本地数据下的 `logs` 文件夹；也可点击「选择文件夹」或展开输入绝对路径。选择目录、调整等级和恢复默认都只修改草稿，点击「保存全部设置」后生效。切换位置不会迁移或删除旧日志；「使用默认位置」清空自定义目录。

日志只保存在本机，不上传，任何等级都不记录笔记正文、剪贴板、密码、令牌、网址、完整文件路径或技术堆栈。卡片显示的 `EV-…` 事件编号可用于查找对应业务结果；重复提示会记录来源编号与显示编号的关联，即使关闭相应通知，启用的日志仍按等级输出。

日志使用有界后台队列，过载时合并记录丢弃数量，不阻塞保存或编辑。最多保留 5 个日志文件，每个不超过 2 MiB，达到上限后轮转应用自己登记的文件；同名未知文件、链接和其他应用占用的位置不会被强行替换。目录不可用时会提示一次，笔记与其他功能仍可继续使用，可选择其他位置。退出和更新前会尝试刷新，迁移前会释放日志句柄。

「设置 → 存储 → 空间概览」包含默认或当前自定义位置中已登记的日志文件；不会为统计日志而扫描自定义目录中的其他文件。与资料库或应用本地数据重叠的文件只计算一次；不能安全核对时显示统计不完整。

## 笔记目录与大文件

打开 Markdown 笔记后，点击工具栏的侧栏图标（悬停显示「显示目录」）显示标题目录，再次点击或使用目录右上角的隐藏图标关闭。目录默认根据编辑器实际空间选择左侧、上方或浮层；可从「目录位置」选择自动、左侧、右侧、上方或浮层。所选位置和显示状态会记住；窄窗下左右侧栏会暂时变为浮层，变宽后恢复，避免挤占正文。目录按标题层级显示，点击标题左侧箭头可展开或收起子章节，也可使用「全部展开」「全部收起」。点击标题跳转到对应位置，当前章节会高亮；编辑标题或切换笔记后目录随之更新。目录获得焦点时，可用上下方向键选择、左右方向键展开收起、Enter 跳转，Esc 隐藏目录并返回开关。目录仅显示在笔记中，学习摘要不显示目录。

历史快照列表纵向滚动，快照时间与滚动条分开显示。笔记不设固定文件大小上限，导入、编辑、保存、草稿恢复和同步均可处理较大的 Markdown 文件；实际处理速度取决于设备与内容。图片预览不再设固定张数上限。
