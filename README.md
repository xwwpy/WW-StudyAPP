# WW-StudyApp

本地优先的学习笔记应用，支持 Windows、Linux 和 macOS。

- **Markdown 笔记**：自适应内容宽度、连续编辑、代码高亮、图片、目录、文件夹、搜索与自动草稿；安全 HTML 图片与链接、自定行列的表格与完整列操作、自定义多级列表。
- **原文档阅读**：导入 PDF、DOCX，在应用内按页面阅读、翻页和缩放；保留原件及历史版本，不覆盖原文件，不进行 OCR。也支持导入常见文本格式。
- **学习计时**：今日学习固定计时卡片，支持专注、正计时、倒计时，以及支持透明背景和整体缩放的桌面小组件。
- **学习与复习**：Markdown 学习摘要、版本关联、间隔复习、历史记录与学习统计。
- **个性化**：亮色、暗色及多套可编辑主题预设，透明颜色、Markdown 样式、全局与分类继承的选中/未选中项外观，以及快捷键设置。
- **设置工作区**：可调整宽度的分类树、窄窗抽屉、Ctrl+F 全局定位、嵌入预览及跨页共享草稿；统一保存或放弃全部修改。
- **本地资料管理**：外部文件跟踪、与正文保存独立的三种快照策略、变化预览与勾选保存、笔记历史、图片管理、备份恢复与可逐层展开的空间管理；旧版资料库可直接选择原目录继续使用。
- **可选同步**：WebDAV、本地文件夹和 NAS。
- **提示与诊断**：结构各异的 Toast、HUD、Snackbar、Banner、确认对话框、任务与分享面板；独立布局和外观的菜单、Popover 与 Tooltip，按用途分区排队、场景内容继承，以及可配置日志与只读文件完整性检查。
- **应用内更新**：版本提示、分版本更新说明、签名校验与保留资料库的安装重启。
