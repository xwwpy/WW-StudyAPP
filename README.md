# WW-StudyApp

本地优先的学习笔记应用，支持 Windows、Linux 和 macOS。

- **Markdown 笔记**：连续编辑、代码高亮、图片、表格、分层目录、文件夹、搜索与自动草稿。
- **学习计时**：今日学习固定计时卡片，支持专注、正计时、倒计时，以及同步显示的桌面小组件。
- **学习与复习**：Markdown 学习摘要、版本关联、间隔复习、历史记录与学习统计。
- **个性化**：亮色、暗色、自定义主题，Markdown 样式、选区与快捷键设置。
- **本地资料管理**：外部文件跟踪、笔记历史、图片管理、备份恢复与空间统计。
- **可选同步**：WebDAV、本地文件夹和 NAS。
- **应用内更新**：版本提示、分版本更新说明、签名校验与保留资料库的安装重启。
